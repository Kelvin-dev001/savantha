# Client stories

One Markdown file per story (files starting with `_` are ignored). A story is published only
when `consent: true` and a consent date are recorded. Stories describe the process and the
experience, never investment returns or performance.

```yaml
---
client: A family business in Mombasa # how the client agreed to be described
service: trade-finance # a service slug
quote: They explained every cost before we signed anything.
consent: true
consentDate: 2027-01-15
order: 1
---
```
